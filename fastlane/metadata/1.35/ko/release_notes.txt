• 선수 검색: 선수 관리 페이지에서 이름, 별명, 번호로 검색
• 음성 성공 애니메이션: 음성 입력 후 선수 아바타와 동작 애니메이션 표시, 1.2초 후 페이드 아웃
• 선수 별명: 여러 별명 추가 가능, 음성으로 별명 인식
• 이벤트 자동 스크롤: 새 이벤트 발생 시 자동으로 상단 스크롤
• 기간 다중 선택: 여러 쿼터 선택하여 통계 데이터 확인
• 경기 시간 표시: 실제 플레이 시간 표시 (타임아웃 제외)
• 목록에 시작-종료 시간: 각 경기의 시작 및 종료 시간 표시
• 플러스마이너스 수정: 쿼터별과 전체 간 일관성 개선
• 성능 개선 및 버그 수정
