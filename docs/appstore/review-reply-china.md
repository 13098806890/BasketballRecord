Dear App Store Review Team,

Thank you for your review feedback on version 1.35 of 篮球生涯手帐 (BasketballRecord).

We have carefully reviewed the issues raised and made the following changes:

**Metadata Cleanup**
All references to "OpenAI" and "Anthropic" have been removed from the app's description and metadata across all 10 supported languages. The description now only mentions "DeepSeek" and generic terms like "AI services".

**Region-Specific Compliance (Code Level)**
In version 1.35, we added runtime region detection (`Locale.current.region == "CN"`). When the app is used in mainland China, only the DeepSeek AI provider is shown and selectable in the settings UI. Other providers (OpenAI, Anthropic) are completely hidden from the interface. This ensures compliance with Chinese regulations on deep synthesis technologies.

**Review Notes Confirmed**
We have updated the Review Notes in App Store Connect to confirm that AI provider selection has been suppressed for the China mainland storefront.

We believe this version now fully complies with the Administrative Provisions on Deep Synthesis of Internet-based Information Services in China. DeepSeek operates with the necessary permits and合规 documentation required under Chinese law.

Please let us know if any further changes are needed.
