# App Store 上架文档

本目录提供 `篮球生涯` 在 App Store 上架常用的说明页面与文案模板。

## 文档列表

- `privacy-policy.md`：隐私政策（可作为 App Store Connect 的隐私政策 URL 内容源）
- `support.md`：支持页面（可作为 App Store Connect 的支持 URL 内容源）
- `terms-of-use.md`：使用条款页面（可选）
- `app-store-metadata.md`：App Store 元数据草案（名称、副标题、描述、关键词、更新说明）
- `review-notes.md`：App 审核备注模板（提交审核时可复制）
- `publish-guide.md`：如何把 Markdown 发布为可访问网页（满足 App Store URL 要求）

## 使用建议

1. 先把文档里的 `TODO` 信息替换成你的真实内容（邮箱、网址、公司/个人信息、生效日期）。
2. 将 `privacy-policy.md` 和 `support.md` 发布为公网 `HTTPS` 页面后，再填入 App Store Connect。
3. 每次发版前同步更新 `app-store-metadata.md` 和 `review-notes.md`。
