# 支持页面（Support）

欢迎使用 `篮球生涯`。如果你在使用过程中遇到问题，可通过本页面获取帮助。

## 常见问题

### 1) 为什么有些按钮不可点击？

请先确认：

- 已完成“新比赛”配置；
- 当前节次已开始；
- 比赛未暂停且未结束；
- 已选中需要记录数据的球员。

### 2) 比赛数据会丢失吗？

应用支持比赛过程自动保存。建议你在关键节点手动“存到历史”，并定期导出备份。

### 3) 更换手机后如何迁移数据？

在旧设备中先导出球员/球队/比赛数据，再在新设备中导入。

### 4) 删除后能恢复吗？

通常不可恢复。请在删除前先导出备份。
