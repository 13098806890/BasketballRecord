# Adaptive A visual prototype

This independent SwiftUI target keeps the existing top-level navigation and visible content from the iPhone 17 baseline screenshots.

The selected editorial style is implemented without raster background posters. The background is drawn with SwiftUI Canvas using low-contrast paper color, corner arcs, and a restrained geometric block. It contains no language-specific text, so localization and device-size changes do not require new background images.

The prototype keeps the current management, career, settings, and score entry points. The score screen is a protected placeholder and is not redesigned. The prototype uses mock data only and does not change the product's persistence model.
